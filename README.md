# پنل مدیریتی آکادمی شیما شادمان — نسخه SQLite فایل‌محور

این نسخه پنل را به یک اپ دسکتاپ Electron تبدیل می‌کند تا مشاور بتواند یک پوشه روی کامپیوتر خود انتخاب کند. دیتابیس واقعی SQLite با نام `shima-academy.sqlite` داخل همان پوشه ذخیره می‌شود.

## اجرا

1. Node.js نسخه 18 یا جدیدتر را نصب کنید.
2. داخل همین پوشه اجرا کنید:

```bash
npm install
npm start
```

3. در اولین اجرا پوشه ذخیره‌سازی را انتخاب کنید.
4. تمام تغییرات دانش‌آموز، برنامه، آزمون و یادداشت در همان فایل SQLite ذخیره می‌شوند.
5. دفعه بعد که برنامه را باز کنید، همان دیتابیس دوباره خوانده می‌شود و پنل بر اساس اطلاعات آن نمایش داده می‌شود.

## تغییر دیتابیس

از بخش «تنظیمات» روی «انتخاب پوشه» بزنید. اگر در پوشه انتخاب‌شده فایل `shima-academy.sqlite` وجود داشته باشد، همان دیتابیس بارگذاری می‌شود؛ اگر وجود نداشته باشد، دیتابیس فعلی در آن پوشه ساخته/ذخیره می‌شود.

## ساختار

- `index.html` رابط کاربری و منطق پنل
- `main.js` مدیریت فایل SQLite و انتخاب پوشه در Electron
- `preload.js` پل امن بین رابط و سیستم فایل
- `package.json` تنظیمات اجرای Electron

نکته: خود دیتابیس در سیستم کاربر ذخیره می‌شود؛ localStorage فقط برای حالت اجرای مستقیم فایل در مرورگر به عنوان fallback باقی مانده است.

### نسخه بهبود ظاهری
این build شامل اصلاحات responsive، فاصله‌گذاری، overflow، فرم‌ها، modal/drawer، جدول‌ها، hover/focus و منوی موبایل است و منطق SQLite را تغییر نمی‌دهد.

### دیتابیس خالی برای تست
تمام داده‌های نمونه/Mock حذف شده‌اند. دیتابیس با جدول‌های خالی اجرا می‌شود تا اطلاعات واقعی توسط مشاور ثبت شود.

### اصلاح نهایی دیتابیس خالی
داده‌های seed/mock و همچنین داده‌های ذخیره‌شده محلی از build قبلی در اولین اجرای این نسخه پاک‌سازی می‌شوند. پس از آن، اطلاعاتی که خودتان ثبت می‌کنید حفظ خواهد شد.

### اصلاح نمودار میانگین تراز
نمودار دیگر نباید از مقادیر ثابت/Mock استفاده کند؛ داده نمودار باید از رکوردهای واقعی دیتابیس محاسبه شود و در حالت بدون داده، Empty State نمایش داده شود.
